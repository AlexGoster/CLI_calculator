# CLI Calculator

Калькулятор с историей вычислений в командной строке.

## Использование

```bash
# одиночное вычисление
python calculator.py 5 + 3

# показать историю
python calculator.py --history

# очистить историю
python calculator.py --clear

# интерактивный режим
python calculator.py
```

В интерактивном режиме вводится выражение из трёх частей: `число оператор число`
(например `5 + 3`). Выход: `q`, `quit` или `exit`.

История сохраняется в файл `calculator_history.json`.

## Возможности

- Операторы: `+`, `-`, `*`, `/`
- Проверка деления на ноль и корректности чисел
- История вычислений с возможностью очистки
